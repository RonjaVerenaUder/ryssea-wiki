# Sechem des Ton-Ren-Anem

## Überblick

Das Sechem des Ton-Ren-Anem ist ein mächtiges Artefakt im Besitz von [[Charaktere/Helden/Sethos Gang/Sethos|Sethos]]. Es kann auf Elemente eingestimmt werden und verstärkt die Zauberei des Trägers auf das aktive Element erheblich. Über Zeit können mehrere Elemente im Sechem gespeichert werden.

## Funktion

### Einstimmung

Das Sechem kann auf **ein Element gleichzeitig** aktiv eingestimmt sein. Das Einstimmungsritual dauert je nach Element unterschiedlich lang. Es können alle **10 Elemente** im Sechem gespeichert werden. Sobald mehrere Elemente gespeichert sind, dauert das Wechseln zwischen ihnen nur noch **5 Ticks**.

### Boni auf das aktive Element

- **1× Heldenstufe** als Schwerpunkt auf das eingestimmte Element
- **2W6 weniger GLeP-Kosten** (mindestens 1)
- **+1W6 zusätzlicher Schaden** bei Einzelzielen
- **+2W6 zusätzlicher Schaden** bei Zonen

### Aurazauberei & Anführen

- **+5 SW-Wert**
- **1× Heldenstufe** als Schwerpunkt auf *Inspirieren*

## Enthaltene Elemente

| Element | Quelle | Besonderheit |
|---------|--------|--------------|

**Falkenauge** *(mit [[Artefakte/Halsreif des Horus|Halsreif des Horus]])*

- Reichweite +0,5 Grundreichweite
