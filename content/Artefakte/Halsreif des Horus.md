# Halsreif des Horus

## Grunddaten

|                    |                      |
| ------------------ | -------------------- |
| **Typ**            | Halsreif             |
| **Verbunden mit**  | [[Götter/Horus\|Horus]]              |
| **Besitzer**       | [[Charaktere/Helden/Sethos Gang/Sethos\|Prinz Sethos]] |

## Funktion

### Falkenform (klein)

Der Träger des Halsreifs kann sich in einen kleinen Falken verwandeln.

| Eigenschaft          | Wert      |
| -------------------- | --------- |
| **Ausführungsdauer** | 10 Ticks      |
| **Zielform**         | Falke (klein) |
| **Kosten**           | 1 SP pro Hin- und Rückverwandlung |
