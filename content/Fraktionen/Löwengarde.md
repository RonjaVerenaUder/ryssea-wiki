# Löwengarde

Militärische Einheit in [[Sarakant]] auf [[Atlas/Sultannii/Sultannii|Sultannii]].

## Grunddaten

|                |                                              |
| -------------- | -------------------------------------------- |
| **Sitz**       | [[Sarakant]]                                 |
| **Typ**        | Militär / Garde                              |

## Bekannte Mitglieder

- [[Jashari N'Baaka]] — Ehemalige Sklavin, in der Löwengarde ausgebildet (geflohen)
- [[Nuri N'Kaan]] — Ausbilder

## Charakter

Die Löwengarde bildet Kämpfer unter harten Bedingungen aus — einschließlich Sklaven. Methoden umfassen körperliche Züchtigung, hartes Training und versuchte Gehirnwäsche.
