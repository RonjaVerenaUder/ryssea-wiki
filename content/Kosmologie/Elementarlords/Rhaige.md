# Rhaige Al'Kronriam

Elementarlord des Feuers. Einer der 10 [[Elementarlords]], erwacht aus dem Element Feuer.

## Grunddaten

|                |                                              |
| -------------- | -------------------------------------------- |
| **Element**    | Feuer                                        |
| **Voller Name** | Rhaige Al'Kronriam                          |
| **Heiligtum**  | [[Kronrimar]] (Vulkangebirge auf [[Baryia (Splitter)\|Baryia]]) |

## Verehrung

- Die [[Kultur der Zwerge|Zwerge]] verehren den Feuerlord unter einem zwergischen Namen
- [[Jashari N'Baaka]] ist ihm durch ihren Vertrauten [[Willow]] verbunden
- Im [[Verborgenes Tal|Verborgenen Tal]] auf [[Sultannii]] wurde ein "Geist" des Feuerlords gesichtet
