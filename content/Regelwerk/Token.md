# Token

Um das Spiel um eine anfassbare Komponente zu erweitern, wird mit verschiedenen Token gearbeitet. Jeder Spieler bekommt zu seinem Charakter einen kleinen Beutel mit farbigen Glassteinen, die verschiedene Dinge repräsentieren.

---

## Übersicht

| Token | Farbe | Startwert | Maxwert | Regeneration |
|---|---|---|---|---|
| [[Regelwerk/Schicksalspunkte\|Schicksalspunkte]] | Dunkelblau / Hellblau | 2 + Stufe | Startwert + 3 | 1 pro Spieltag |
| Fraktal-Token | Weiß | 0 | beliebig | Spielleitungsvergabe |
| Götter-Segen | Gelb / Orange | 0 | 6 | Spielleitungsvergabe |
| Hilfe! | Rot | Spielerzahl | Spielerzahl | nach Spielleitungsentscheid |
| Special Action! | Grün | nach Spielleitungsentscheid | nach Spielleitungsentscheid | nach Spielleitungsentscheid |

---

## Schicksalspunkte

**Farbe:** Dunkelblau / Hellblau

| | |
|---|---|
| **Startwert** | 2 + Heldenstufe |
| **Maxwert** | Startwert + 3 |
| **Regeneration** | 1 pro Spieltag. Bei Beginn eines Abenteuers zurück auf Startwert. Kann nach Ermessen der Spielleitung vergeben werden. |

**Anwendung:** Siehe [[Regelwerk/Schicksalspunkte|Schicksalspunkte & Schicksalsgaben]].

> [!info] Neu: Schicksalspunkt zu Götter-Segen
> Schicksalspunkte können in Götter-Segen umgewandelt werden.

---

## Fraktal-Token

**Farbe:** Weiß

| | |
|---|---|
| **Startwert** | 0 |
| **Maxwert** | beliebig |
| **Regeneration** | Nach Spielleitungsvergabe, oft als Belohnung von Abenteuern oder Questerfolgen. |

**Anwendung:** An geeigneter Stelle eintauschbar gegen ein [[Regelwerk/Fraktale|Fraktal]] aus dem Angebot der Spielleitung — entweder im Abenteuer (wenn es Fraktale zu kaufen gibt) oder zwischen den Abenteuern.

---

## Götter-Segen

**Farbe:** Gelb / Orange

| | |
|---|---|
| **Startwert** | 0 |
| **Maxwert** | 6 |
| **Regeneration** | Spielleitungsvergabe bei besonders gottgefälligen Taten. Diese müssen auch mit dem Gott in Verbindung zu bringen sein, vor allem in den Augen der Welt — das kann eine besonders gute Predigt sein, ein passend angebrachter Segen, oder im Prinzip alles, was dem Gott potentiell mehr Anhänger bringt. |

> [!abstract] Liebling der Gottheit
> Charaktere mit diesem Vorteil erhalten **1 Punkt pro Spieltag** frei (in Orange, maximal 1).

**Anwendung:** Bonus beim Sprechen von Liturgien. Der Bonus erfolgt gezielt über Token, nicht mehr nach Ermessen der Spielleitung.

---

## Hilfe!

**Farbe:** Rot

| | |
|---|---|
| **Startwert** | Spielerzahl |
| **Maxwert** | Spielerzahl |
| **Regeneration** | Nach Spielleitungsentscheid. |

**Anwendung:** Gruppenressource. Kann ausgegeben werden, wenn die Gruppe nicht weiterkommt oder Tipps von der Spielleitung haben möchte.

---

## Special Action!

**Farbe:** Grün

| | |
|---|---|
| **Startwert** | nach Spielleitungsentscheid |
| **Maxwert** | nach Spielleitungsentscheid |
| **Regeneration** | nach Spielleitungsentscheid |

**Anwendung:** Noch offen.
