# Abgeleitete Werte

Aus den [[Eigenschaften]] und Talenten berechnete Werte. Grundlage ist die Abkürzungsliste der Eigenschaften (BW, KK, KO, ENT, IN, LG, CH, MAG) und die Größenklasse (GK).

## Grundwerte

| Wert | Formel |
|---|---|
| **Geschwindigkeit** (GS) | BW + GK |
| **Initiative** (Ini) | (IN + IN + BW + ENT) / 2 |
| **Lebenspunkte** (LeP) | KO + GK |
| **LeP-Regeneration** | KO + KK |
| **Geistige Lebenspunkte** (GLeP) | ENT + LG |
| **GLeP-Regeneration** | KO + MAG |
| **Erinnern** | (LG + LG + IN) / 2 |
| **Zauberaffinität** | Heldenlevel × 2 |
| **Kanalisierungspunkte** | Heldenlevel × 2 |

## Passive Verteidigungswerte

| Wert | Formel (SW-Wert des Talents) |
|---|---|
| **Verteidigungswert** (VT) | BW + KK + Talentwert [[Talente\|Akrobatik]] |
| **Körperliche Resistenz** (kR) | CH + ENT + Talentwert Selbstbeherrschung |
| **Geistige Resistenz** (gR) | KO + ENT + Talentwert Zähigkeit |

## Aktive Abwehr (je 4 Ticks auf der [[Regelwerk/Kampf/Kampfregeln#Die Tickleiste|Zeitleiste]])

| Aktion | Formel |
|---|---|
| **Parade** | SW-Wert im passenden Waffentalent + 2W10 |
| **Schildparade** | SW-Wert in Zähigkeit + 2W10 |
| **Ausweichen** | SW-Wert in Akrobatik + 2W10 |

## Mögliche Boni für eine Probe

**SW-Wert-Verbesserungen:**

- **Ausrüstungsgegenstände:** 2 + (Heldenlevel × 2)
- **Zauberei:** 2 + (Heldenlevel × 2)
- **Umstände:** siehe Tabelle Umstände
- **Einstellung bei sozialer Interaktion:** siehe Tabelle Soziale Interaktion

**EW-Verbesserungen (Erfolgswürfel):** beliebig oft nutzbar, aber man kann nie mehr EG haben als Talentpunkte im angewendeten Talent.

**EG-Verbesserungen (Erfolgsgrade):**

- **Ausrüstungsgegenstände:** Heldenlevel
- **Zauberei:** Heldenlevel
