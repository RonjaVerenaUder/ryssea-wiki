# Waffen

Waffenlisten für [[Kampfregeln|Kampf]]. Jede Waffe gehört zu einem [[Talente#Kampftalente|Kampftalent]]. Merkmale sind unten erklärt.

> [!abstract] Spaltenlegende
> **TP** = Schaden der Waffe (Trefferpunkte) · **DK** = Distanzklasse · **WGS** = Waffengeschwindigkeit · **BF** = Bruchfaktor · **Voraussetzung** = Mindest-Eigenschaftswerte
>
> **TP/BW** und **TP/KK** (Format **X/Y**) = zusätzlicher Schaden aus der Eigenschaft: Ab Eigenschaftswert **X+Y** gibt es **+1** Schaden, bei **X+2Y** +2, bei **X+3Y** +3 usw. — kurz: **+1 Schaden je Y Punkte über X**.

## Waffenmerkmale

*38 Merkmale. Stufen 0 = kein Stufenwert, sonst steigerbar.*

| Merkmal | Typ | Stufen | Beschreibung |
|---|---|---|---|
| Ablenkend | Nahkampf | 3 | Die Waffe ist biegsam und daher schwer vorhersehbar, oder sie ist mit Tüchern, Bändern und ähnlichem versehen, die den Gegner verwirren sollen. Die Grundschwierigkeit einer Aktiven Abwehr gegen diese Waffe erhöht sich um 5 pro Stufe des Merkmals. |
| Deckung | Schild | 0 | Ein Schild mit diesem Merkmal zählt, sofern er geführt wird, als leichte Deckung im Fernkampf. Dies ist nur bei Schilden mit mindestens einer VTD von 2 möglich. |
| Defensiv | Nahkampf, Schild | 4 | Bei einer erfolgreichen Aktiven Abwehr mit einer solchen Waffe oder einem solchen Schild erhält der Abenteurer einen zusätzlichen Erfolg pro Stufe des Merkmals. Bei Waffen ohne das Merkmal Zweihändig und bei Schilden kann dies auch genutzt werden, wenn man sie zusätzlich zu einer Hauptwaffe führt – in diesem Fall gelten die entsprechenden Regeln zum Einsatz von Schilden und Parierwaffen. Sollten zwei Gegenstände mit dem Merkmal Defensiv geführt werden, gilt stets nur der höhere Bonus (und natürlich nur der Bonus von Gegenständen, für die auch eine passende Fertigkeit für die Aktive Abwehr genutzt wurde). |
| Doppelwaffe | Nahkampf | 0 | Mit dieser Waffe können die Meisterschaften zum Kampf mit zwei Händen genutzt werden. |
| Dornen | Schild | 0 | Ein Schild mit diesem Merkmal ist besonders gut für den Kampf geeignet. Es ist möglich, Manöver der allgemeinen Nahkampfmeisterschaften mit dem Schild durchführen, sofern der Kämpfer sie in der verwendeten Waffenfertigkeit erlernt hat. Außerdem gilt der Schild im Sinne von Verbesserungen, Verzauberungen und allen anderen positiven regeltechnischen Belangen als Waffe (kann aber natürlich weiterhin nach den Schildregeln eingesetzt und zum Beispiel nicht entwaffnet werden). |
| Durchdringend | Fernkampf, Nahkampf | 3 | Für jede Stufe dieses Merkmals kann 1 Punkt der gegnerischen Schadensreduktion ignoriert werden, egal aus welcher Quelle diese stammt. |
| Entwaffnend | Nahkampf | 3 | Für jede Stufe dieses Merkmals zählt die Last dieser Waffe um 1 Punkt erhöht, wenn es um die erlaubte Nutzung des Manövers Entwaffnen geht. |
| Entwaffnungsimmunität | Nahkampf | 0 | Eine Waffe mit diesem Merkmal kann nicht von dem Manöver Entwaffnen betroffen werden. |
| Entwaffnungsschutz | Nahkampf | 4 | Um eine Waffe mit diesem Merkmal mit dem Manöver Entwaffnen zu beeinflussen, sind zusätzliche Erfolge in Höhe der Stufe notwendig. Werden diese Erfolge nicht erreicht, gilt der Angriff nach den üblichen Regeln als Streiftreffer. |
| Exakt | Nahkampf | 3 | Bei einem Schadenswurf mit dieser Waffe werden so viele Würfel zusätzlich geworfen, wie die Stufe des Merkmals beträgt. Die zusätzlichen Würfel sind die gleiche Würfelart, die beim Schadenswurf der Waffe verwendet wird. Die höchsten Ergebnisse zählen für den Schadenswurf, wobei nur so viele Würfel gewertet werden, wie beim Schaden der Waffe angegeben sind. |
| Ferndistanz | Fernkampf | 0 | Mit dieser Fernkampfwaffe kann normalerweise maximal die sechsfache Grundreichweite erreicht werden, was 5 Erfolge benötigt. Bei einer Waffe mit diesem Merkmal erhöht sich die maximale Reichweite auf die siebenfache Grundreichweite. Hierfür sind entsprechend 6 Erfolge notwendig. |
| Freihändig | Nahkampf | 0 | Eine Waffe mit diesem Merkmal benötigt entweder keine Hand (z.B. Schuhsporn) oder ist flexibel genug, dass es möglich ist, mit der gleichen Hand eine weitere gewöhnliche Waffe zu führen. Dies gilt natürlich nur im Rahmen des gesunden Menschenverstandes: Es ist beispielsweise nicht möglich, zwei Panzerhandschuhe oder ähnliche Waffen übereinander zu ziehen. |
| Gehärtet | Rüstung, Schild | 0 | Der Verteidigungsbonus eines Schildes oder einer Rüstung mit diesem Merkmal ist um 1 Punkt erhöht. Der Tick-Zuschlag ist im Gegenzug ebenfalls um 1 Punkt erhöht. |
| Improvisiert | Fernkampf, Nahkampf | 0 | Diese Gegenstände des Alltags sind eigentlich nicht für den Kampf geeignet. Allerdings verbessern sich ihr Schaden und ihre Waffengeschwindigkeit um je 2 Punkte, wenn der Kämpfer über die Meisterschaft Improvisation in der entsprechenden Kampffertigkeit verfügt. |
| Kletterhilfe | Nahkampf | 0 | Wird eine Waffe mit diesem Merkmal als Hilfsmittel beim Klettern eingesetzt, kann der Abenteurer negative Umstände durch fehlende Ausrüstung ignorieren. |
| Kritisch | Nahkampf | 3 | Der Schaden eines Angriffs einer Waffe mit diesem Merkmal erhöht sich für jeden Schadenswürfel, der die maximale Augenzahl würfelt, um die Stufe des Merkmals. |
| Lange Waffe | Nahkampf | 0 | Die Waffe ermöglicht es, aus einer größeren Distanz anzugreifen. Ein gegnerisches Lösen aus dem Kampf erhält einen Malus in Höhe von 3 Punkten, ein eigenes einen Bonus in Höhe von 3 Punkten. |
| Nahkampftauglich | Fernkampf | 0 | Die Fernkampfwaffe kann auch als Nahkampfwaffe mit eigenen Werten verwendet werden. |
| Paarwaffe | Nahkampf | 0 | Werden zwei Waffen mit diesem Merkmal beidhändig geführt, erhalten abwechselnde Angriffe dieser Waffen einen Ausrüstungsvorteil in Höhe von 2 Punkten. |
| Parierwaffe | Nahkampf | 0 | Die Waffe kann auch als Parierwaffe genutzt werden, wenn man sie zusätzlich zu einer anderen Waffe in der Nebenhand führt. In diesem Fall werden sie ähnlich wie ein Schild genutzt, die Aktive Abwehr erfolgt aber immer über die zugehörige Kampffertigkeit der Parierwaffe mit ihren Eigenschaften. Bei einer solchen Nutzung fällt eine Behinderung an, die dem Wert hinter dem Merkmal entspricht. Sollte mit der Waffe bei Führung als Parierwaffe auch angegriffen werden, gelten die Regeln für den Kampf mit zwei Händen. Parierwaffen finden Sie der Einfachheit halber sowohl in der Waffenliste als auch in der Liste der Schilde und Parierwaffen. Die bei der Liste der Parierwaffen genannte Behinderung entspricht der Behinderung durch dieses Merkmal, muss also nicht doppelt angerechnet werden. |
| Primitiv | Fernkampf, Nahkampf, Rüstung | 0 | Die Waffe oder die Rüstung ist einfach gearbeitet und daher von nicht sehr guter Qualität. Verursacht eine Waffe mit diesem Merkmal bei einem Gegner, der eine Rüstung ohne das Merkmal Primitiv trägt, Schaden, wird dieser Schaden um 2 Punkte reduziert. Die Rüstung ist einfach gearbeitet und daher von nicht sehr guter Qualität. Sie erhält stets den vollen Schaden einer Waffe, selbst wenn diese das Merkmal Primitiv trägt. |
| Reiterwaffe | Fernkampf, Nahkampf | 3 | Eine Waffe mit diesem Merkmal ist unabhängig von sonstigen Einschränkungen im Reiterkampf einsetzbar. Setzt der Abenteurer sie vom Rücken eines Reittiers ein und verfügt über die Meisterschaft Reiterkampf, verursacht er für jede Stufe des Merkmals einen zusätzlichen Schadenspunkt. |
| Rückkehrend | Fernkampf | 0 | Eine Waffe mit diesem Merkmal fliegt nach dem Angriff, der nicht getroffen hat, aber kein verheerender Misserfolg oder Patzer war, zu ihrem Nutzer zurück. Dazu benötigt sie ihre WGS. Anschließend kann sie mit Gegenstand verwenden aufgenommen werden (was in diesem Fall auch als Reaktion möglich ist). Die Meisterschaft Schnellziehen verleiht hierbei einen Bonus in Höhe von 2 Ticks. |
| Scharf | Nahkampf | 4 | Alle Schadenswürfel einer Waffe mit diesem Merkmal werden immer als mindestens der Wert der Stufe des Merkmals gewertet, egal was eigentlich gewürfelt wurde. Eine Waffe mit 1W6+2 Schaden und dem Merkmal Scharf 2 richtet also selbst dann 4 Punkte Schaden an, wenn der Schadenswürfel eine 1 zeigt. Dies gilt nicht für zusätzliche Schadenswürfel aus Manövern, Zaubern oder sonstigen Quellen. |
| Schildwall | Schild | 0 | Wenn ein Schild mit diesem Merkmal zu einer Aktiven Abwehr eingesetzt wird und die Probe gelingt (also die Schwierigkeit, üblicherweise 15, erreicht wird), erhöht sich die Schadensreduktion des Nutznießers der Abwehr um 2 Punkte (üblicherweise der Kämpfer selbst, möglicherweise mit der Meisterschaft Verteidiger aber auch ein Gefährte) |
| Stabil | Rüstung | 0 | Eine Rüstung mit diesem Merkmal ist besonders widerstandfähig gearbeitet. Die Durchdringung eines Angriffs (gleich ob von der Waffe, von Meisterschaft oder aus anderer Quelle) wird vollständig ignoriert. Dafür ist die Rüstung weniger flexibel: Die Behinderung ist um 1 Punkt erhöht. |
| Standfestigkeit | Rüstung | 0 | Eine Rüstung mit diesem Merkmal lässt harte Schläge besonders gut abgleiten, sodass der Träger schwieriger aus dem Gleichgewicht zu bringen ist. Gegen Angriffe, die die Position des Trägers verändern (ihn also zum Beispiel niederwerfen ([[Kampfregeln#Kampfpositionen|Liegend]]) oder abdrängen sollen), ist sein KW um 3 Punkte erhöht. Dafür ist die Rüstung schwerer und unhandlicher: Entweder Tick-Zuschlag oder Behinderung sind um 1 Punkt erhöht. |
| Stumpf | Fernkampf, Nahkampf | 0 | Der von der Waffe verursachte Schaden zählt vollständig als Betäubungsschaden. Dies gilt auch für zusätzlich Schaden aus Manöver, nicht aber aus Quellen wie etwa Zaubern. |
| Teilbar | Nahkampf | 0 | Mittels einer Aktion Gegenstand verwenden kann aus zweier dieser Waffen eine entsprechende zweihändige Waffe hergestellt werden. |
| Treffsicher | Fernkampf | 0 | Eine Fernkampfwaffe mit diesem Merkmal ist besonders treffsicher. Die erste Erhöhung der Grundreichweite erfordert vom Abenteurer keinen zusätzlichen Erfolg. Mit der Meisterschaft Starker Wurfarm benötigen bei Wurfwaffen die beiden ersten Erhöhungen keinen zusätzlichen Erfolg |
| Umklammern | Nahkampf | 0 | Mit dieser Waffe ist das Manöver Umklammern einsetzbar (Zustand [[Zustände#Umklammert|Umklammert]]). |
| Unauffällig | Fernkampf, Nahkampf | 0 | Dieses Merkmal funktioniert wie die Verbesserung Unauffällig. |
| Unhandlich | Nahkampf | 0 | Die Verteidigung des Trägers erhält bei Führung dieser Waffe einen Malus in Höhe von zwei Punkten. |
| Vielseitig | Nahkampf | 0 | Waffen mit diesem Merkmal können sowohl ein- als auch zweihändig geführt werden. In zweihändiger Führung erhöht sich ihr Schaden um 3 Punkte |
| Wattiert | Rüstung | 0 | Eine Rüstung mit diesem Merkmal verfügt über eine besondere, gehärtete Wattierung, die die Wucht heftiger Schläge besser verteilt. Der Bonusschaden durch freie Manöver Wuchtangriff wird halbiert. Dafür ist die Rüstung unhandlich: Sowohl Tick-Zuschlag als auch Behinderung sind um 1 Punkt erhöht. |
| Wuchtig | Nahkampf | 0 | Bei Waffen mit diesem Merkmal verursacht das freie Manöver Wuchtangriff 2 statt 1 zusätzlichen Punkt Schaden pro eingesetzten Erfolg. |
| Wurffähig | Nahkampf | 0 | Die Nahkampfwaffe kann auch als Wurfwaffe mit eigenen Werten verwendet werden. |
| Zweihändig | Fernkampf, Nahkampf | 0 | Die Waffe muss mit zwei Händen geführt werden. Sie kann nicht im berittenen Kampf eingesetzt werden, sofern sie nicht auch das Merkmal Reiterwaffe besitzt. |
