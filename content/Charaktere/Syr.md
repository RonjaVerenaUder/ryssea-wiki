# Syr

Mentorin und Trainingspartnerin von [[Dana Lonnert]] an der Akademie in [[Fraystein]].

|              |                                              |

## Beschreibung

Syr ist zusammen mit [[Coran]] eine von Danas wichtigsten Mentorinnen an der Akademie. Beide genießen großen Respekt in [[Fraystein]]. Dana hat unter Syr intensiv trainiert — ihr durchtrainierter Körper ist unter anderem das Ergebnis dieses Trainings.
